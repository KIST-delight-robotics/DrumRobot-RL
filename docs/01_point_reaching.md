# Point Reaching

> **한 줄 요약**: 양팔 9-DOF 로봇의 양손 스틱 끝(팁)이 임의로 주어진 3D 목표 점 두 개로 수렴하도록 학습시킨 첫 번째 실험.
>
> **Status**: 부분 성공 (체크포인트 800K steps)
>
> **시기**: 2026-02

---

## 1. 동기 (Why)

Isaac Lab + skrl(PPO) 위에서 **9-DOF 양팔 로봇이 강화학습으로 의미 있는 공간 제어 동작을 학습할 수 있는지** 가장 단순한 형태로 검증하기 위한 실험.

드럼 연주라는 최종 목표는 여러 요소가 결합되어 있다:

- 양팔의 공간 좌표 제어
- 정확한 타격 동작 (수직 운동 + 접촉)
- 악보 타이밍에 맞춘 시간적 조율
- 다중 악기에 대한 목표 선택

처음부터 이 모두를 동시에 학습시키려 하면 보상 설계와 디버깅이 어려워지므로, **가장 단순한 요소인 "공간 좌표 도달"만** 분리하여 학습 가능성을 확인하는 워밍업 실험으로 설계.

---

## 2. 문제 정의 (What)

- **목표**: 임의로 샘플링된 3D 점 두 개(왼손/오른손 각각)에 양손 스틱 끝이 수렴
- **성공 기준**: 양손 모두 목표 점에서 0.1m 이내에 10 스텝 연속 유지

## 3. 설계 (How)

### 관측 공간 (30차원)

| 항목 | 차원 | 정규화 방식 |
|---|---|---|
| 관절 위치 | 9 | `(q - center) / half_range`, [-1.5, 1.5] 클리핑 |
| 관절 속도 | 9 | `vel / 5.0`, [-5, 5] 클리핑 |
| 목표 위치 (양손) | 6 | `(t - center) / half_range`, [-2, 2] 클리핑 |
| 위치 오차 (팁 - 목표) | 6 | 목표 half_range로 나눠 정규화 |

### 행동 공간 (9차원)

연속 행동 `[-1, 1]`, `action_scale = 0.03` 적용 → 각 관절에 작은 위치 증분 명령.

### 보상 설계

```
reward = w_dist * (-dist_sum)              # 거리 음의 보상 (w=0.3)
       + w_exp  * exp(-k * dist_sum)        # 가까워질수록 가파른 양의 보상 (w=3.0, k=4.0)
       - w_action  * ||action||^2          # 행동 크기 패널티 (w=0.002)
       - w_joint_vel * ||joint_vel||^2     # 관절 속도 패널티 (w=0.0005)
       - w_limit * limit_barrier           # 관절 제한 근접 패널티 (w=0.2, margin=10°)
       - w_died * 1[out_of_limit]          # 제한 초과 시 사망 패널티 (w=1.0)
       + success_bonus * 1[hold_10_steps]  # 성공 유지 보너스 (+2.0)
```

**설계 의도:**
- `dist_term`: 멀리 있을 때도 약하게나마 신호를 주기 위한 linear shaping
- `exp_term`: 목표 근접 시 보상을 비선형적으로 증폭하여 정밀 수렴 유도
- `limit_barrier`: hard limit 도달 전에 미리 패널티를 주는 soft barrier (margin 10° 안쪽)
- `died`: 관절 범위 초과 시 에피소드 종료 + 패널티 (early termination)

### 환경 설정

| 항목 | 값 | 비고 |
|---|---|---|
| 병렬 환경 | 128 | `num_envs` |
| sim_dt | 1/120s | |
| decimation | 2 | policy dt = 1/60s |
| action_scale | 0.03 | 작게 잡아 안정성 우선 |
| 관절 stiffness | 200.0 | implicit actuator |
| 관절 damping | 10.0 | |
| self collision | disabled | |
| 학습 step | 800K | |

- **에피소드 길이**: 5초 (decimation=2, sim_dt=1/120s → policy dt=1/60s, 약 300 스텝)

### 관절 가동 범위 ("joint_range" vs "joint_limit")

특이한 점은 두 가지 범위가 분리되어 있다는 것:

- **`joint_range`**: 리셋 시 초기 자세 샘플링 범위 (좁음, 안전한 영역)
- **`joint_limit`**: 학습 중 허용 범위 (넓음, 실제 하드웨어 한계)

예: `waist_joint`은 초기엔 ±30° 범위에서 시작하지만 학습 중에는 ±90°까지 허용.

→ 초기에 안전한 영역에서 시작해서 점차 탐색 범위를 넓혀가도록 설계.

## 5. 무엇이 잘 됐는가

- **Isaac Lab + skrl(PPO) 학습 파이프라인이 동작함을 확인** — 이후 모든 실험의 기반
- **9-DOF 양팔의 동시 제어가 RL로 수렴 가능**함을 확인
- **`exp(-k·dist)` shaping의 효과**: 멀리서는 약한 linear 신호로 방향 잡고, 가까워지면 exp 신호로 정밀 수렴
- **soft barrier + early termination 조합**: 관절 제한을 부드럽게 학습시킬 수 있음 (margin 안에서는 패널티, 넘으면 종료)

## 6. 한계와 막힌 점

- **시작하자마자 관절 범위를 넘는 방향으로 학습됨**
  - 보상이 음수이고 성공을 경험하지 못하면 에피소드를 빠르게 끝내는 것이 유리
  - 보상이 일반적인 상황에서 양수이도록 수정

- **성공 기준으로 거리 조건만 두면 목표에 머무르지 않고 스쳐지나감**
  - 일정 거리 이내 일정 스템 이상 머물러야 성공으로 인정

- **성공하며 에피소드를 끝내지 않고 가까운 거리만 유지**
  - 성공하고 에피소드를 끝내는 것보다 거리 보상을 지속적으로 먹는 것이 유리
  - 성공 보상 크기를 키우면 해결될 수 있음 (현재 체크 포인트는 해결 안된 상태)

## 8. 회고 / 배운 점

- **관측 설계**
  - "현재 상태 + 목표 상태 + 오차"를 모두 관측에 포함하는 패턴
  - 특히 절대 위치 보다 **오차(err)를 명시적으로 넣는 것**이 학습 효율에 도움이 되는 것으로 보임

- **보상의 두 층 구조 (linear + exp)**
  - 단일 보상 형태로는 "멀리서의 신호 강도"와 "근처에서의 정밀도"를 동시에 챙기기 어려움
  - 두 항을 가중 합하는 패턴이 효과적

- **`joint_range`와 `joint_limit` 분리**
  - 초기 자세를 안전한 영역에서 시작시키는 것이 학습 안정성에 기여
  - 이후 task에서도 유사한 분리 구조 유지
