# Rhythmic Drum Striking

> **한 줄 요약**: 미래 악보 관측을 "다음 K개 타격 이벤트"로 압축하고, 양손 역할 분담을 보상으로 직접 강제하며, 안 되는 드럼에 학습 신호를 자동 증폭하는 세 메커니즘을 결합해 양팔 9-DOF 로봇이 랜덤 악보에 따라 타격하는 정책을 학습시킨 실험.
>
> **Status**: 부분 성공 (체크포인트 1M steps)
>
> **시기**: 2026-05

---

## 1. 동기 (Why)

여기까지의 리듬 타격 시도에서 학습은 진전이 있었지만 실용 수준에 한참 못 미쳤다. 세 가지 구조적 한계가 남아 있었다:

1. **거대 sparse 관측의 비효율**: 미래 30 step × 8 drum = 240차원의 RDS one-hot을 MLP 정책에 그대로 던지는 것이 표현력 측면에서 비효율적
2. **양손 분담 학습 부재**: 특정 드럼이 극단적으로 안 되는 양상은 정책이 양손 역할을 학습하지 못했다는 신호
3. **부정확한 타격 비율이 높음**: 잘못 침 페널티를 약화하니 탐색은 풀렸지만 정확도가 함께 떨어짐

이 실험은 위 세 한계를 **세 가지 새로운 메커니즘**으로 동시에 응답한다:

> 관측을 "다음 K개 타격 이벤트 + 각 이벤트의 시간 정보"로 압축하고, 양손 할당을 보상이 직접 결정하며, 안 되는 드럼에 가중치를 자동으로 증폭한다.

부수적으로 타격 판정도 더 엄격하게 만들어 약한 hit이나 스쳐 지나가는 hit이 인정되지 않게 한다.

---

## 2. 문제 정의 (What)

- **악보(RDS)**: 처음부터 **완전 랜덤으로 생성된** 악보를 사용. MIDI 기반 pretraining 단계 없이 학습이 진행됨.
- **목표**: 각 RDS 노트에 대해 양손 중 정해진 손이 ±10 step 윈도우 안에 그 드럼을 침
- **타격 판정 강화**: xy 반경, z 마진, 임팩트 속도 임계치, 준비 높이를 모두 더 엄격하게 설정해서 "진짜 타격"만 인정

---

## 3. 설계 (How)

### 관측 공간 (94차원)

미래 악보를 거대한 RDS one-hot 윈도우가 아니라, **30차원 event-based 표현**으로 정의한다.

**"다음 K=3개의 타격 이벤트, 각각이 어떤 드럼이고 얼마나 가까운 시점에 있는지"**:

```
next_hits: (K=3, 8 drum + 1 time + 1 valid) = 30
  - [:K, :8]    = 해당 이벤트의 타겟 드럼 multi-hot
  - [:K, 8]     = 정규화된 time_to_hit (0~1, 다음 1초 안에서)
  - [:K, 9]     = valid 플래그 (그 자리에 이벤트가 있는지)
```

정책에 던지는 메시지가 "**다음 세 타격이 각각 어떤 드럼, 얼마나 가까운 시점**"으로 명확해진다. sparse one-hot이 아니라 **이벤트 순서 + 시간 거리**로 압축된 표현. 시계열 모듈 없이 MLP가 미래를 파악할 수 있도록 표현을 가공.

총 관측: 관절 자세·속도(18) + 양손 팁 위치(6) + 드럼 위치(24) + **다음 타격 이벤트(30)** + 타격 준비 비트(16) = 94.

### 행동 공간

9차원 연속 행동, 관절 각속도 명령 (정책 출력에 π를 곱하고 환경 시간 간격으로 적분).

### 양손 할당 기반 phase 보상

이 실험의 핵심 메커니즘 중 하나. **양손 할당을 보상이 먼저 결정하고, 그 결과 할당된 손에만 phase 보상을 적용**한다.

다음 노트의 타겟 드럼이 1개일 때:
- 두 손의 거리를 비교해 **가까운 손에 자동 배정**
- 그 손에 대해서만:
  - 아직 안 친 상태면 → 내려치는 속도를 보상
  - 이미 친 상태면 → 다시 올라가는 속도를 보상
- 다른 손은 이 보상에서 제외

타겟이 2개일 때:
- 가능한 두 가지 할당(L→A,R→B vs L→B,R→A) 중 **총 비용이 작은 매칭** 선택
- 매칭된 손 각각에 위와 같은 phase 보상 적용

**효과**: 정책이 "왼손은 왼쪽 드럼 그룹, 오른손은 오른쪽 드럼 그룹"의 분담을 보상으로부터 직접 학습한다. 양손 모두에 동일하게 phase 보상을 주던 이전 구조와 달리, 어느 손이 어느 드럼에 가야 하는지가 보상 신호에 묶인다.

### 드럼별 자동 가중치 (adaptive weighting)

매 episode 종료 시점에서, 8개 드럼 각각에 대해:

```
success_ratio_per_drum = (해당 드럼의 성공 hit 수) / (해당 드럼의 전체 hit 시도 수)
w_inst_success_per_drum = 1.0 / (success_ratio + ε)
# 평균이 1이 되도록 정규화
w_inst_success_per_drum /= w_inst_success_per_drum.mean()
```

이 가중치가 다음 episode부터 성공 보상에 곱해진다:

```
success_reward = Σ_drum (성공 여부 × w_inst_success_per_drum)
```

**이전 episode에서 안 됐던 드럼에 다음 episode의 성공 보상이 더 크게 매겨진다.** 잘 안 되는 드럼이 자동으로 부각되는 self-balancing 구조. 사람이 매번 가중치 튜닝하지 않아도 작동하는 자동 curriculum.

### 타격 판정의 엄격화

"진짜 타격"의 정의를 더 좁힌다:

| 파라미터 | 값 |
|---|---|
| 드럼 xy 반경 | 0.13 m (더 정확히 정렬해야 hit) |
| z 마진 | 0.07 m (z 정밀도 강화) |
| 최소 임팩트 속도 | 0.2 m/s (더 빠른 하향 속도 필요) |
| 준비 높이 | 0.18 m (rearm까지 더 높이 들어올려야) |

스쳐 지나가는 가짜 hit이나 약한 hit이 성공으로 인정되지 않게 한다. 정책에게 더 명확한 motion 요구.

### 보상 구조의 재구성

보상의 무게중심을 dense 거리 항에서 goal 항으로 옮긴다:

- **Goal 보상**(성공 / 잘못 침 / 놓침 / 시간 정확도): 큰 가중치 (5.0, 1.5, 2.0, 5.0)
- **Dense 거리**(진행, 근접): 작은 가중치 (4.0, 1.5)
- **Dense motion**(상향/하향 속도): 중간 가중치 (0.35, 0.30)

**goal 보상의 총 합이 dense 거리 보상의 약 2.5배가 된다.** 정책이 "다음 타겟에 가까이 가기"보다 "정확히 치기"에 강하게 인센티브를 받는다. 부정확한 타격을 막으면서도, 잘못 침 가중치(1.5)는 탐색을 봉인하지 않는 중간값.

시간 정확도 보상이 5.0으로 큼 — 윈도우 안에 친 것뿐 아니라 **정확한 타이밍**에 친 것을 적극적으로 보상.

### 환경 설정

- 병렬 환경 128
- 에피소드 길이 5초
- RDS: 처음부터 완전 랜덤
- 학습 step 1M

성공률 77%로, 04번(13%)과 05번(18%)에서 한 자릿수 배 이상 상승했다. 잘못 침과 놓침이 동시에 줄어, 05번에서 정확도와 적극성이 trade-off에 갇혀 있던 양상에서 빠져나왔다.

**관측 압축이 작동했다.** 304차원 → 94차원으로 줄였는데 성공률은 4배 이상 좋아졌다.

**드럼별 편차가 좁혀졌다.** 가장 높은 미드(82%)와 가장 낮은 플로어(70%) 사이가 1.17배다. 04번에서 5배에 달했던 편차가 거의 사라졌고, 어느 드럼도 학습에서 소외되지 않았다.

**잘못 침의 분포에 패턴이 있다.** 가까운 드럼끼리는 헷갈리고(미드 40%, 하이 44%), 먼 드럼끼리는 안 헷갈린다(하이햇 9%, 라이드 8%, 크래시 5~9%). 정책이 적극적으로 시도하지만 인접 드럼들 사이의 정밀한 구분에서는 한계가 있다.

영상으로도 양손이 분담된 영역에서 자연스러운 사이클로 타격하는 모습이 나온다. **남은 실패의 결은 이전 단계들과 질적으로 다르다 — "못 친다"나 "부정확하다"가 아니라, "가까운 드럼끼리만 헷갈린다"로 좁혀졌다.**

## 5. 무엇이 잘 됐는가

- **세 가지 메커니즘이 모두 의도대로 작동**: 관측 압축, 양손 할당 기반 phase 보상, 자동 드럼별 가중치 — 셋 다 메트릭으로 효과 검증됨.
- **관측 압축의 위력 확인**: 304차원을 94차원으로 줄였는데 학습 성능이 오히려 3배 좋아짐. **표현이 압축될 때 학습이 더 잘 되는 경우**가 있다는 것을 직접 경험. 거대 sparse one-hot은 MLP가 추출하기 어려운 정보 구조였다.
- **양손 할당 보상의 분담 효과**: 드럼별 편차가 7배에서 1.7배까지 좁혀짐. 양손 역할을 보상이 강제하니 정책이 그 분담을 학습.
- **자동 가중치의 self-balancing**: 별도 스케줄링 없이 episode마다 잘 안 되는 드럼이 자동으로 부각됨. 사람이 매번 튜닝하지 않아도 작동하는 메커니즘.
- **Goal-dominant 보상 구조**: 성공 보상을 dense 보상의 2배 이상으로 키우자 정책이 정확도에 직접 인센티브 받음. dense는 가이드, sparse가 목표라는 정합성.
- **타격 판정 엄격화와 가중치 증가의 조합**이 진짜 타격 동작 학습에 도움. 약한 hit으로 점수 얻는 함정이 닫힘.
- **처음부터 랜덤 RDS로 학습 가능**해짐. MIDI pretraining 단계 없이 진행됨. 학습 효율이 충분히 끌어올려진 결과로 해석.

## 6. 한계와 막힌 점

성공률 59%는 시리즈 정점이지만 **여전히 실용적인 드럼 연주 수준은 아니다**.

- **놓침 41%는 여전히 큼**. 특히 라이드(58%), 좌크래시(45%), 우크래시(51%) 같은 멀리 있는 드럼의 도달 실패가 누적. 양손 할당이 분담은 잘 했지만, "특정 손이 충분히 멀리 갈 수 있는가"의 reachability 자체가 부족.
- **가까운 드럼들 사이의 잘못 침이 큼**: 스네어 20%, 플로어 21%, 미드 36%, 하이 34%. 가까운 드럼끼리 헷갈리는 정책. 관측에서 다음 이벤트의 multi-hot은 어느 드럼인지 알려주지만, 정책이 그 multi-hot을 충분히 정밀하게 해석하지 못한다.
- **변경 사항이 한꺼번에 들어감**: 관측 압축, 양손 할당 보상, 자동 가중치, 타격 판정 엄격화, 가중치 재구성, RDS 소스. 어떤 요소가 가장 큰 진전을 만들었는지 ablation 없음.
- **자동 가중치의 분산 가능성**: 어려운 드럼에 가중치가 너무 커지면 학습이 그쪽으로 쏠리고, 잘 됐던 드럼이 다시 안 되는 oscillation이 발생할 수 있음. 메트릭은 안정적이지만 학습 곡선을 보면 그런 진동이 있을 수 있다 (보상 그래프 첨부 후 확인 필요).
- **MIDI 분포에서의 성능 미검증**: 이번 실험은 완전 랜덤 RDS만 사용. 실제 음악 패턴(빠른 연타, 동시 양손 노트, 트리플렛 등)에서 같은 정책이 작동할지는 별도 평가 필요.
- **타이밍 정확도의 정량 평가 부족**: 성공은 ±10 step 윈도우 안의 hit만 보지만, 윈도우 안에서도 정확도는 다름. 시간 정확도 보상으로 부분적으로 다루지만 메트릭으로 추적되지 않음.
- **드럼 표면 통과가 완전 차단되진 않음**: 가중치가 작아서 신호가 약함. 페널티 가중치 강화나 hit 판정 자체 재설계 필요.

## 7. 다음 단계로 넘어간 이유

리듬 타격 시리즈의 정점을 찍었다. 성공률 59%, 드럼별 편차 1.7배는 legacy 단계의 의미 있는 도달점이다. 그러나 실용 수준의 드럼 연주를 위해선 다음이 필요하다:

1. MIDI 분포에서의 검증과 fine-tuning — 랜덤 RDS에서 학습한 정책의 실제 음악 패턴 일반화
2. 타이밍 정확도의 명시적 평가 — 단순 윈도우 통과가 아닌 정확한 시점 hit의 비율 측정
3. 양손 분담을 정책 구조에서 강화 — 보상에서 강제하는 것 외에 multi-head 정책이나 양손 별도 네트워크 등의 구조적 prior
4. Sim-to-real 검증 — 속도 명령 표현으로 옮긴 의도가 실제 하드웨어로 transfer되는지

이런 방향들은 **legacy 단계를 넘어 본격적인 연구 task**로 확장되어야 한다. 이 시리즈는 공간 도달 → 단발 타격 → 리듬 타격으로 이어지는 학습 가능성을 검증한 baseline 실험으로서 마무리.

## 8. 회고 / 배운 점

- **표현이 작아질 때 학습이 더 잘 되는 경우**. 거대 sparse one-hot을 압축된 event 표현으로 줄이면서 성능이 3배 좋아졌다. "관측에 정보를 다 넣자"가 아니라 "**정책이 추출하기 좋은 구조로 정리해서 넣자**"가 더 중요. 시계열 task에 시계열 모듈을 쓸 수 없다면, 시간 정보를 압축된 표현으로라도 옮겨야 한다.
- **보상으로 양손 역할을 강제하는 게 정책 구조보다 빨랐다**. 양손 별도 네트워크 같은 구조적 prior 없이도, 할당 비용이 양손 분담 학습에 충분했음. 정책 구조 변경 전에 보상 측면에서 강제할 여지가 있는지를 먼저 확인해야 한다.
- **자동 가중치의 self-balancing**. 단 몇 줄의 코드인데 드럼별 편차를 크게 좁힘. 사람이 매번 가중치 튜닝하지 않아도 작동하는 self-balancing 메커니즘의 위력.
- **Goal-dominant 보상이 dense-dominant보다 잘 작동**. 단발 타격 실험도 sparse goal에 큰 보상을 두는 구조였고, 이번 실험도 마찬가지. **dense는 가이드, sparse가 진짜 목표**라는 정합성이 학습 안정성에 기여.
- **이전 회고의 진단들이 정확히 응답되었다**. "거대 sparse 시퀀스"는 관측 압축으로, "양손 분담 부재"는 할당 기반 보상으로, "드럼별 편차"는 자동 가중치로. **실패 진단의 정확성이 다음 실험 설계의 성공 확률을 직접 결정**한다는 것을 시리즈 전체로 검증.
- **시리즈로 보면 reward shaping의 패턴이 보임**. 점 도달(거리) → 드럼 도달(거리+속도) → 단발 타격(phase) → 리듬 시도(거리+sparse) → phase 부활 → 압축+할당+adaptive. **각 단계가 이전 단계의 한 가지 결함을 핵심적으로 응답**하는 형태로 진화. 한 번에 모든 걸 잡으려 하지 않고 한 결함씩 다루는 점진적 설계가 유효.
- **legacy 시리즈의 가치는 결과 자체보다 사고 과정**. 59% 성공률은 실용 수준이 아니지만, 6번의 실험을 통해 RL 시스템의 어떤 부분을 어떻게 진단하고 응답하는지에 대한 **사고 도구**가 누적되었다. 이것이 다음 연구 단계에서 활용 가능한 가장 큰 자산.
